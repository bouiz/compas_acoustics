# compas_acoustics



## Installation

Stable releases can be installed from PyPI.

```bash
pip install compas_acoustics
```

To install the latest version for development, do:

```bash
git clone https://github.com/gramaziokohler/compas_acoustics.git
cd compas_acoustics
pip install -e ".[dev]"
```
