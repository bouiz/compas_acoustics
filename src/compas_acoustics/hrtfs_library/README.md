# HRTF sets

The head-related transfer function sets the `Auraliser` and `Hybrid.binaural` use. Each file carries its own
licence in its SOFA metadata (`GLOBAL_License`); the notes below are copied from there.

## KEMAR_Knowl_EarSim_SmallEars_FreeFieldComp_48kHz.sofa

The default set. The AXD HRTF database of Imperial College London ("HRTF C"): a KEMAR with Knowles EarSim small ears,
in-the-ear microphones with the blocked-ear-canal method, measured with an exponential sweep, free-field compensated, 48 kHz.
Converted to SOFA with AMTatARI.
