# Anechoic Soundfiles Library

Anechoic source recordings used by `compas_acoustics` for auralisation and related demos.

## Source

These files come from the [OpenAIR Anechoic Data](https://www.openair.hosted.york.ac.uk/?page_id=310) collection (University of York).

OpenAIR publishes audio recordings captured under anechoic conditions, including early and modern musical instruments, singing, speech, and other sources.

## Files in this folder

| File | Description | OpenAIR set |
| --- | --- | --- |
| `speech.wav` | Speech recording | [Speech - Core Take.wav](https://webfiles.york.ac.uk/OPENAIR/Anechoic/speech-macbeth/) |
| `viola.wav` | Modern viola, C major detache | [modern-viola-c-major-detache.wav](https://webfiles.york.ac.uk/OPENAIR/Anechoic/modern-viola/mono/) |
| `trumpet.wav` | Handel Trumpet | [tr-1788d-piece4-sl.wav](https://webfiles.york.ac.uk/OPENAIR/Anechoic/handel-trumpet/mono/) |
