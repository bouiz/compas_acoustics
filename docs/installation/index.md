# Installation

There are two ways to install `compas_acoustics`:

* **[In Rhino 8 and Grasshopper](grasshopper.md)**, from Rhino's Package Manager. It installs the plugin's components;
  the Install Worker component then creates the worker, the Python environment they compute in. Choose this to work on
  the canvas.
* **[In Python](python.md)**, from PyPI, to script with the package in your own environment.

The two are independent: the Grasshopper plugin does not need a Python installation of your own.
